# 微信公众号技术文章排版模板

将一篇技术博文排版成可直接粘贴到微信公众号后台的 HTML。全部样式内联在标签上，不依赖任何外部 CSS / JS，粘贴进微信编辑器不会掉样式。

## 示例文章

《从 0 到 1：我们如何用 3 个月重构了百万级用户的推荐系统》——一篇关于推荐系统「召回—粗排—精排—重排」四阶段重构的实战复盘。

成品文件：[`output/推荐系统重构_公众号排版.html`](output/推荐系统重构_公众号排版.html)

## 使用方法

1. 浏览器打开 `output/推荐系统重构_公众号排版.html`
2. `⌘A` 全选 → `⌘C` 复制
3. 粘贴到公众号后台图文编辑器，样式即生效

## 排版规格

| 维度 | 取值 |
| --- | --- |
| 容器最大宽度 | 680px |
| 正文字号 / 行高 | 16px / 1.8 |
| 段间距 / 章间距 | 16px / 32px |
| 主色（标题、技术术语） | `#1E6FD9` |
| 关键数据强调色 | `#E5484D` |
| 警示框（踩坑经验） | `#FFFBF0` 底 / `#EFA93C` 边 |
| 深色强调卡（结论、链路总览） | `#16233A` |

## 版式组件

- **标签卡**：左侧 4px 色条 + `01–04` 数字徽标，用来拆分架构的四个阶段
- **流程图卡**：竖排节点 + 箭头，表现 Kafka → Flink → Redis 这类数据链路
- **警示框**：橙色描边 + 「坑 N」角标，内部再嵌白底小卡区分「教训 / 解决方案」
- **数据表**：深色表头 + 斑马纹行，数字列 `white-space:nowrap` 防止在手机宽度下折行
- **行内代码**：等宽字体 + 浅底圆角，用于 `FAISS`、`DeepFM`、`point-in-time` 这类术语

## 兼容性注意

- 只用 `<section>` / `<p>` / `<span>` / `<table>` 等微信编辑器保留的标签，样式一律走 `style` 属性
- 不使用 `<style>`、`<script>`、伪元素、CSS 变量、`position`、渐变色
- 表格列宽按 390px 手机视口实测分配，避免数字被拆行
